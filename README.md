# bropty

**bropty** is a headless terminal library for the Bro ecosystem: VT/xterm
emulation, the cell grid and scrollback a renderer reads, and the PTY
plumbing that feeds it. It has no rendering, windowing or scripting
dependency (no bro, no bronze); C++20, its own CMake and ctest suite.

## Layout

| Header | What |
|--------|------|
| `bropty/parser.h` | Williams-style VT parser: strict UTF-8 (U+FFFD per maximal subpart) decoded in ground state only, flat CSI params with colon sub-parameter bits, OSC/DCS/SOS/PM/APC strings with bounded size. Feeds a `ParserSink`. |
| `bropty/terminal.h` | The emulator (`Terminal`) and the embedder interface (`TerminalHost`: replies to the PTY, bell, title/icon, cwd, OSC 52 clipboard, notifications, progress, OSC 133 marks, palette changes, APC). |
| `bropty/cell.h` | 8-byte `Cell` (first code point, width role, cluster/protect bits, style id), per-row sparse `ClusterMap` for multi-code-point graphemes, `RowView`. |
| `bropty/style.h`, `bropty/color.h` | Interned `Style` (colors, attributes, underline style/color, hyperlink) with a garbage-collected `StyleTable`; `Palette`. |
| `bropty/grid.h` | Screen storage: contiguous cells plus a row-index map (scrolling rotates indices), per-row flags/clusters, dirty bits. |
| `bropty/scrollback.h` | History as compactly encoded logical lines in shared arena blocks; capacity in rows at the current width; rewraps on width change without re-encoding. |
| `bropty/unicode.h` | Unicode 17 widths, UAX #29 grapheme segmentation, emoji properties (tables generated by `tools/gen_unicode.cpp`). |
| `bropty/session.h` | `Session`: a `Terminal` attached to a PTY, with key/mouse/paste encoding. |
| `bropty/pty.h`, `bropty/key_encoder.h` | ConPTY / POSIX PTY, key and mouse encoders. |

Resize reflows the primary screen and its history as one buffer of logical
lines, keeping the cursor (and the DECSC-saved cursor) on their characters;
the alternate screen is cropped. Mode 2027 grapheme clustering is on by
default (`TerminalOptions::grapheme_clustering`).

## Building and testing

```bash
# Windows (Visual Studio generator)
cmake -B build
cmake --build build --config Release
ctest --test-dir build -C Release -LE probe

# Linux / macOS (one build dir per config)
cmake -B build-release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
ctest --test-dir build-release -LE probe
```

Every test is a real ctest whose exit status reflects its checks (no
`assert()`), so Release builds test too. Besides the hand-written suites,
`test_unicode` runs the official `GraphemeBreakTest.txt` and `test_vterm_diff`
is a differential oracle: random VT streams run through bropty and through a
vendored libvterm (test-only, MIT), comparing every cell, the cursor,
history and CPR replies; failures are shrunk to a minimal stream. Its
handful of deliberate libvterm/xterm differences are listed in
`tests/vterm_diff_gen.cpp` and `tests/third_party/libvterm/CMakeLists.txt`.
Tests labelled `probe` drive real programs and are not part of the suite.

## Example

```cpp
#include <bropty/session.h>

int main() {
    bropty::TerminalOptions opts;
    opts.cols = 80;
    opts.rows = 24;
    bropty::Session session(opts);

    std::shared_ptr<bropty::IPtyProcess> pty = bropty::create_pty();
    bropty::PtyConfig config;
#if defined(_WIN32)
    config.command = "cmd.exe";
#else
    config.command = "/bin/bash";
#endif
    pty->spawn(config);
    session.attach_pty(pty);

    while (pty->is_running()) {
        session.update();  // PTY output -> emulator; replies go back to the PTY
        const bropty::Terminal& t = session.terminal();
        for (int y = 0; y < t.rows(); ++y) {
            bropty::RowView row = t.row(y);  // cells, styles, clusters, flags
            (void)row;                       // render with Skia / HarfBuzz ...
        }
    }
}
```
